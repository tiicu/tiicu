### What is tiicu?

tiicu is the first custom emulation frontend for Nintendo Switch — a controller-first, native C++ interface designed for performance, simplicity, and long-term portability.

It provides a console-quality user experience with:
- Unified multi-console launcher
- Automatic game organization
- Embedded emulator cores
- Controller-first navigation
- Zero user configuration required
